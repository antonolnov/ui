# WorkHere ATS - Система управления кандидатами

Полнофункциональный интерфейс ATS (Applicant Tracking System) для рекрутеров.

## 🚀 Быстрый старт

### Вариант 1: Открыть напрямую
Просто откройте файл `index.html` в браузере (Chrome, Firefox, Safari, Edge).

### Вариант 2: Локальный сервер (Python)
```bash
python3 -m http.server 8000
```
Затем откройте http://localhost:8000

### Вариант 3: Node.js сервер
```bash
npx serve .
```

## 📋 Функциональность

### Дашборд
- Утренние приоритеты и задачи на день
- Статистика по вакансиям, кандидатам, интервью
- Лента последней активности
- Уведомления о срочных задачах

### Вакансии
- Список всех вакансий с фильтрацией
- Детальная информация по вакансии
- Воронка кандидатов
- Статусы: активные, на паузе, закрытые

### Кандидаты
- Таблица кандидатов с поиском и фильтрами
- Детальная карточка кандидата
- История изменений (timeline)
- Фидбеки от интервьюеров
- Заметки

### Воронка (Pipeline)
- Канбан-доска по этапам
- Drag-and-drop перемещение (визуально)
- Фильтрация по вакансии
- Быстрые действия

### Интервью
- Список запланированных интервью
- Календарный вид
- Назначение интервью
- Фидбек после интервью

### Талант-пул
- База сильных кандидатов для будущего
- Теги и условия возврата
- Напоминания о контакте

### Офферы
- Создание и согласование офферов
- Статусы: согласование, отправлен, принят, отклонен
- Условия оффера

### Аналитика
- Воронка найма
- Эффективность источников
- Время найма
- Причины отказов

### Настройки
- Профиль пользователя
- Уведомления
- Конфигурация

## 🎯 Пользовательские сценарии (JTBD)

Интерфейс разработан для поддержки всех ключевых сценариев рекрутера:

1. **Утренний контроль** - быстрый обзор приоритетов
2. **Обработка откликов** - быстрый triage новых кандидатов
3. **Движение по воронке** - перевод кандидатов между этапами
4. **Интервью** - назначение и отслеживание
5. **Фидбек** - сбор и анализ обратной связи
6. **Офферы** - создание и согласование
7. **Аналитика** - понимание эффективности процесса
